¿Qué es MarketTracker?

Un backend FastAPI con un worker de ingestión asyncio, TimescaleDB (solo velas cerradas) y Redis (precio en vivo, caché y pub/sub), más una app Flutter multiplataforma servida como web tras Nginx. Se despliega con GitHub Actions → GHCR → Coolify sobre Oracle Cloud.

  • Precios en vivo, velas históricas y gráfico de velas nativo.
  • Alertas, señales técnicas explicables y backtesting.
  • Cartera, libro de operaciones con informe fiscal (FIFO en EUR) y eventos corporativos.
  • Paper trading con Alpaca (sin dinero real) y notificaciones por Telegram.
